# Design

## Context

Proyek belum memiliki kode aplikasi sebelum change ini. Foundation-auth membangun fondasi teknis Next.js (App Router, TypeScript), Drizzle ORM dengan PostgreSQL native Windows, Better Auth untuk autentikasi admin, dan infrastruktur pengujian Vitest dengan PostgreSQL asli. Mengacu pada TDR D1-D5, D10 dan BR-14.

## Goals / Non-Goals

**Goals:**
- Setup struktur proyek Next.js App Router dengan TypeScript strict mode di root repo
- Konfigurasi koneksi PostgreSQL native Windows dengan Drizzle ORM dan validasi environment dengan Zod (modul env tervalidasi dengan fungsi murni)
- Implementasi autentikasi admin dengan Better Auth (database-backed sessions dengan masa berlaku absolut 7 hari, satu role Admin)
- Proteksi rute `/admin` dengan helper `requireAdminSession()` (page/Server Action) dan `getAdminSessionOrNull()` (Route Handler)
- Halaman login dengan form client Better Auth (HTTP ke route handler)
- Skrip seed untuk membuat akun admin pertama dengan factory `createAuth({ allowSignUp: true })`
- Infrastruktur pengujian Vitest dengan binding database tunggal, execution serial, dan alias path
- Rate limiting login dengan penyimpanan database (N request per jendela waktu per IP)

**Non-Goals:**
- Tabel domain (venue, paket, reservasi, pembayaran) - masuk change berikutnya
- Halaman publik, kalender, captcha untuk customer
- Bukti Booking dan PDF
- Cron/job terjadwal
- Galeri dan object storage
- Playwright (hanya Vitest untuk integration test)
- Styling lanjutan (Tailwind standar saja)
- Deploy ke Vercel

## Decisions

### A. Lokasi Aplikasi: Root Repo

Aplikasi ditempatkan di root repo bersama `.opencode/`, `openspec/`, dan `docs/`.

**Scaffold Strategy:**

**[BELUM TERVERIFIKASI]** Flag non-interaktif create-next-app (`--import-alias "@/*"` dan `--use-npm`). Perlu verifikasi di dokumentasi Next.js CLI.

Gunakan folder sementara di luar repo:

1. Jalankan di folder sementara:
   ```bash
   npx create-next-app@latest next-app --typescript --tailwind --eslint --app --src-dir --import-alias "@/*" --use-npm
   ```

2. Dari folder `next-app`, pindahkan:
   - `package.json`, `package-lock.json`
   - `tsconfig.json`, file konfigurasi Next.js (nama dari generator)
   - `src/app/`, `src/` struktur lainnya
   - `public/` (gabung dengan existing jika ada)
   - File konfigurasi ESLint (dari generator)
   - File konfigurasi CSS/Tailwind (dari generator)
   - `next-env.d.ts`

3. Gabungkan `.gitignore` dari `next-app` dengan existing di repo

4. **Edit `package.json`: ganti `name` menjadi `"venue-booking-system"`**

5. Hapus folder sementara `next-app`

6. Buat manual:
   - `src/lib/env.ts` untuk validasi environment (fungsi murni + const)
   - `src/lib/load-env.ts` untuk loading .env.local (modul efek samping)

   - `src/lib/db/` untuk database instance dan schema
   - `src/modules/auth/` untuk helper functions
   - `migrations/` untuk Drizzle migrations
   - `tests/` untuk Vitest setup dan helpers
   - `scripts/` untuk seed script

### D. Environment Variables dan Validasi Zod

**Modul Pemuatan Env (`src/lib/load-env.ts`):**

Modul dengan efek samping yang memuat `.env.local` dengan path eksplisit. Tidak menimpa variabel yang sudah ada.

```typescript
// src/lib/load-env.ts
import { config } from 'dotenv';
import { resolve } from 'path';

config({
  path: resolve(process.cwd(), '.env.local'),
  override: false,
});
```

**Catatan Impor:**
- `vitest.config.ts` dan `drizzle.config.ts` menggunakan impor **RELATIF** (`./src/lib/load-env`), bukan alias `@/`, karena alias belum berlaku saat berkas konfigurasi dievaluasi
- `scripts/seed-admin.ts` menggunakan impor relatif (`../src/lib/load-env`) atau **[BELUM TERVERIFIKASI - GERBANG]** dukungan path tsconfig tsx. Perlu verifikasi apakah `tsx` mendukung path mapping dari `tsconfig.json`.

Next.js memuat `.env.local` sendiri, jadi `load-env.ts` **tidak** diimpor oleh kode aplikasi.

**Modul Validasi Env (`src/lib/env.ts`):**

Fungsi murni `parseEnv(source)` dan const `env` agar kasus gagal dapat diuji.

```typescript
// src/lib/env.ts
import { z } from 'zod';

const envSchema = z.object({
  DATABASE_URL: z.string().url(),
  BETTER_AUTH_SECRET: z.string().min(32, "BETTER_AUTH_SECRET minimal 32 karakter"),
  BETTER_AUTH_URL: z.string().url(),
  AUTH_SESSION_MAX_AGE: z.coerce.number().int().positive().default(604800),
  NODE_ENV: z.enum(['development', 'production', 'test']).default('development'),
});

export function parseEnv(source: Record<string, string | undefined>) {
  return envSchema.parse(source);
}

export const env = parseEnv(process.env);
```

**Tes untuk env.ts:**
- Tes kasus variabel hilang (misalnya tanpa `DATABASE_URL`)
- Tes kasus format salah (misalnya `BETTER_AUTH_SECRET` terlalu pendek)
- Tes kasus sukses dengan semua variabel valid

### E. Konfigurasi Better Auth Tunggal

**File `src/lib/auth.ts`:**

SATU fungsi `createAuth({ allowSignUp })` dengan SEMUA opsi Better Auth dalam satu blok.

Better Auth mencari `BETTER_AUTH_SECRET` dan base URL dari environment bila opsi tidak diset, tetapi lebih eksplisit meneruskan nilai dari modul `env`.

```typescript
// src/lib/auth.ts
import { betterAuth } from 'better-auth';
import { drizzleAdapter } from 'better-auth/adapters/drizzle';
import { env } from './env';
import { db } from './db';

export function createAuth(options: { allowSignUp: boolean }) {
  return betterAuth({
    secret: env.BETTER_AUTH_SECRET,
    baseURL: env.BETTER_AUTH_URL,
    
    database: drizzleAdapter(db, {
      provider: "pg",
    }),
    
    session: {
      expiresIn: env.AUTH_SESSION_MAX_AGE,
      disableSessionRefresh: true,
    },
    
    emailAndPassword: {
      enabled: true,
      disableSignUp: !options.allowSignUp,
      minPasswordLength: 12,
      maxPasswordLength: 128,
    },
    
    disabledPaths: options.allowSignUp ? [] : ["/sign-up/email"],
    
    rateLimit: {
      enabled: true,
      storage: "database",
      modelName: "rateLimit",
      customRules: {
        "/sign-in/email": {
          max: 5,
          window: 900,
        },
      },
    },
    
    advanced: {
      ipAddress: {
        // [BELUM TERVERIFIKASI] Header IP untuk Vercel
        // Perlu verifikasi header mana yang diisi platform (x-forwarded-for, x-real-ip)
        // dan bahwa header tidak dapat dipalsukan klien
        // ipAddressHeaders: ["..."],
      },
    },
  });
}

// Instance aplikasi
export const auth = createAuth({ allowSignUp: false });
```

**Catatan Konfigurasi:**

- **Secret dan Base URL**: Diteruskan eksplisit dari `env.BETTER_AUTH_SECRET` dan `env.BETTER_AUTH_URL`
- **Sesi**: Masa berlaku absolut `AUTH_SESSION_MAX_AGE` detik (default 604800 = 7 hari), `disableSessionRefresh: true`
- **Email/Password**: `minPasswordLength: 12`, `disableSignUp` tergantung parameter factory
- **Rate Limiting**: 5 request per 15 menit (900 detik) untuk jalur `/sign-in/email`
- **IP Address**: Header IP tepercaya harus diverifikasi untuk platform deployment. Syarat: header harus diisi oleh platform, bukan klien. Jika header dapat dipalsukan, rate limiting TIDAK efektif. Tes yang mengirim header IP sendiri hanya membuktikan limiter membaca header, bukan bahwa limiter aman dari pemalsuan.

**[BELUM TERVERIFIKASI]** Format kunci `customRules`: apakah path relatif terhadap basePath atau absolut? Perlu verifikasi di dokumentasi Better Auth.

**Tabel `rateLimit`**: Dibuat HANYA dari migrasi Drizzle, tidak otomatis saat runtime.

**Referensi:**
- https://www.better-auth.com/docs/reference/options

### H. Proteksi Rute: Dua Helper Functions

Proteksi `/admin` dengan dua helper functions berbeda untuk use case berbeda.

**Helper 1: `requireAdminSession()` - Untuk Page dan Server Action**

```typescript
// src/modules/auth/require-admin-session.ts
import { redirect } from 'next/navigation';
import { auth } from '@/lib/auth';
import { headers } from 'next/headers';

export async function requireAdminSession() {
  const headersList = await headers();
  const session = await auth.api.getSession({ headers: headersList });
  
  if (!session) {
    const originalPath = headersList.get('x-original-pathname') || '/admin';
    redirect(`/login?redirect=${encodeURIComponent(originalPath)}`);
  }
  
  return session;
}
```

**Helper 2: `getAdminSessionOrNull()` - Untuk Route Handler**

```typescript
// src/modules/auth/get-admin-session-or-null.ts
import { auth } from '@/lib/auth';
import { headers } from 'next/headers';

export async function getAdminSessionOrNull() {
  const headersList = await headers();
  return await auth.api.getSession({ headers: headersList });
}
```

**Proxy (Next.js 16+):**

Proxy menangani redirect awal untuk request tanpa cookie. Proxy **menimpa** header `x-original-pathname` dalam REQUEST headers dengan `request.nextUrl.pathname`.

Keputusan: Proxy melakukan **pengecekan optimistis** (cek keberadaan cookie saja) untuk performa. Helper di halaman melakukan pengecekan penuh terhadap database.

**Aturan Cookie:**

**JANGAN hardcode nama cookie** di proxy. Prefiks cookie dapat berubah di production (kemungkinan `__Secure-` untuk secure cookies).

**[BELUM TERVERIFIKASI]** Helper resmi untuk pengecekan cookie sesi. Kandidat: `getSessionCookie` dari `better-auth/cookies`. Perlu verifikasi di dokumentasi Better Auth.

Tes harus membaca **nama dan atribut cookie** dari respons login nyata (header `Set-Cookie`).

```typescript
// proxy.ts (Next.js 16+) atau middleware.ts (Next.js < 16)
import { NextResponse } from 'next/server';
import type { NextRequest } from 'next/server';

export function proxy(request: NextRequest) {
  // Matcher sudah membatasi ke /admin/:path*
  // Tidak perlu cek startsWith('/admin') lagi
  
  // [BELUM TERVERIFIKASI] Nama cookie dan helper getSessionCookie
  // Placeholder: cek keberadaan cookie session (nama harus diverifikasi)
  const hasSessionCookie = false; // Ganti dengan pengecekan cookie yang terverifikasi
  
  if (!hasSessionCookie) {
    const loginUrl = new URL('/login', request.url);
    loginUrl.searchParams.set('redirect', request.nextUrl.pathname);
    return NextResponse.redirect(loginUrl);
  }
  
  // Set header x-original-pathname di REQUEST headers
  const requestHeaders = new Headers(request.headers);
  requestHeaders.set('x-original-pathname', request.nextUrl.pathname);
  
  return NextResponse.next({
    request: {
      headers: requestHeaders,
    },
  });
}

export const config = {
  matcher: '/admin/:path*',
};
```

**Penegakan Statis:**

Tes statis memindai:
- **File dengan `'use server'`** di `src/**`: HARUS memanggil `requireAdminSession()`
- **File page** di `src/app/admin/**/*.{ts,tsx}`: HARUS memanggil `requireAdminSession()`
- **File route** di `src/app/admin/**/route.{ts,tsx}`: HARUS memanggil `getAdminSessionOrNull()`

**Daftar Pengecualian:** Kosong secara default (login lewat klien).

Gunakan **AST parser** untuk memverifikasi PEMANGGILAN.

**Referensi:**
- https://www.better-auth.com/docs/integrations/next

### J. Open Redirect Protection: resolveSafeRedirect()

```typescript
// src/modules/auth/resolve-safe-redirect.ts
export function resolveSafeRedirect(redirectUrl: string | null | undefined): string {
  if (!redirectUrl || typeof redirectUrl !== 'string') {
    return '/admin';
  }
  
  if (
    redirectUrl.startsWith('//') ||
    redirectUrl.startsWith('/\\') ||
    /[\s\t]/.test(redirectUrl)
  ) {
    return '/admin';
  }
  
  if (!redirectUrl.startsWith('/')) {
    return '/admin';
  }
  
  try {
    const parsed = new URL(redirectUrl, 'http://localhost');
    
    if (parsed.origin !== 'http://localhost') {
      return '/admin';
    }
    
    const pathname = parsed.pathname;
    
    if (
      pathname.includes('%2f') ||
      pathname.includes('%2F') ||
      pathname.includes('%5c') ||
      pathname.includes('%5C') ||
      pathname.includes('..') ||
      pathname.includes('\\')
    ) {
      return '/admin';
    }
    
    if (pathname === '/admin' || pathname.startsWith('/admin/')) {
      return pathname;
    }
    
    return '/admin';
  } catch {
    return '/admin';
  }
}
```

### K. Seed Script untuk Admin Pertama

Skrip seed membuat admin pertama dengan validasi, konfirmasi target database, dan penanganan galat.

**[BELUM TERVERIFIKASI - GERBANG]**:
- Dukungan path tsconfig tsx (atau gunakan impor relatif)
- Bentuk argumen `auth.api.signUpEmail` (kemungkinan butuh `name` selain `email` dan `password`)
- Prompt `password` dari `@inquirer/prompts` dengan mask

```typescript
// scripts/seed-admin.ts
import '../src/lib/load-env'; // Import PALING AWAL (relatif)
// Atau: import '@/lib/load-env' jika tsx mendukung path tsconfig [BELUM TERVERIFIKASI - GERBANG]

import { createAuth } from '../src/lib/auth';
import { db } from '../src/lib/db';
import { sql } from 'drizzle-orm';
import { input, password } from '@inquirer/prompts';
import { z } from 'zod';

const emailSchema = z.string().email("Format email tidak valid");

async function main() {
  try {
    // Parse dan tampilkan target database dari DATABASE_URL
    const dbUrl = process.env.DATABASE_URL;
    if (!dbUrl) {
      console.error('DATABASE_URL tidak diset');
      process.exit(1);
    }
    
    const parsed = new URL(dbUrl);
    const hostname = parsed.hostname;
    const dbName = parsed.pathname.slice(1);
    
    console.log(`Target database: ${hostname} / ${dbName}`);
    console.log('Tanpa $env:DATABASE_URL, seed berjalan ke database dev.');
    
    const confirm = await input({
      message: 'Lanjutkan? (y/n):',
    });
    
    if (confirm.toLowerCase() !== 'y') {
      console.log('Dibatalkan');
      process.exit(0);
    }
    
    // Cek admin sudah ada
    const result = await db.execute(sql`SELECT COUNT(*) FROM "user"`);
    const count = Number(result.rows[0]?.count);
    
    if (count > 0) {
      console.error('Admin sudah ada');
      process.exit(1);
    }
    
    // Prompt dan validasi email
    const email = await input({ message: 'Email admin:' });
    const emailValidation = emailSchema.safeParse(email);
    if (!emailValidation.success) {
      console.error(emailValidation.error.issues[0].message);
      process.exit(1);
    }
    
    // Prompt password
    const pwd = await password({ message: 'Password (min 12 karakter):' });
    
    if (pwd.length < 12) {
      console.error('Password minimal 12 karakter');
      process.exit(1);
    }
    
    // Buat auth instance dengan allowSignUp: true
    const seedAuth = createAuth({ allowSignUp: true });
    
    // [BELUM TERVERIFIKASI - GERBANG] Bentuk argumen signUpEmail
    await seedAuth.api.signUpEmail({
      email: emailValidation.data,
      password: pwd,
      // name: ?, // Mungkin diperlukan
    });
    
    console.log(`Admin ${emailValidation.data} berhasil dibuat`);
  } catch (error) {
    console.error('Error:', error);
    process.exit(1);
  } finally {
    // Tutup koneksi pool
    await db.$client?.end();
  }
}

main();
```

import { sql } from 'drizzle-orm';

export async function truncateAll() {
  const result = await db.execute(sql`SELECT current_database()`);
  const currentDb = result.rows[0]?.current_database;

## Risks / Trade-offs

**[PostgreSQL Native Dependency]** → Developer harus install PostgreSQL.

**[Session Database Query]** → Query tambahan per request. Impact minimal.

**[No Password in Env]** → Seed interaktif. Tidak ada otomasi penuh.

**[Test Serial Execution]** → Tes lebih lambat, mencegah race condition.

**[Rate Limiting Database Storage]** → Query per attempt. Impact minimal.

**[Helper Call Enforcement]** → Harus memanggil helper. Mitigasi: Tes statis AST.

**[Rotasi IP]** → Bypass dengan IP pool. Risiko diterima.

**[Proxy Optimistic Check]** → Cookie check optimistis. Trade-off performa vs security.

**[Rate Limiting Header Forgery]** → Jika header dapat dipalsukan, rate limiting tidak efektif. SYARAT: Verifikasi platform mengisi header.

## Migration Plan

**Development Setup:**
1. Clone repository
2. Install PostgreSQL Windows
3. Buat role dan database dengan psql
4. Install dependencies: `npm install`
5. Copy `.env.example` ke `.env.local` dan isi nilai
6. Run migration: `npx drizzle-kit migrate`
7. Run seed: `npx tsx scripts/seed-admin.ts`
8. Start dev server: `npm run dev`

**Production Deployment:**
1. Push code
2. Set environment variable
3. Run migration: `npx drizzle-kit migrate`
4. Seed admin (PowerShell):
   ```powershell
   $env:DATABASE_URL="<production-url>"; npx tsx scripts/seed-admin.ts
   ```
